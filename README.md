\# BankOperationAnalyzer



Курсовая работа: анализ банковских операций.



\## Возможности



\- \*\*Главная страница\*\* — приветствие по времени суток, сводка по картам (расходы, кешбэк), топ-5 транзакций, курсы валют, цены акций S\&P 500.

\- \*\*События\*\* — расходы и поступления за период (неделя / месяц / год / всё время), топ-7 категорий + «Остальное», отдельно переводы и наличные.

\- \*\*Сервисы\*\* — поиск по описанию/категории (регистронезависимый), поиск телефонов, поиск переводов физлицам, топ-3 категорий повышенного кешбэка.

\- \*\*Отчёты\*\* — траты по категории за последние 3 месяца, с декоратором, который сохраняет результат в JSON-файл.

\## Установка



1\. Установите \[Poetry](https://python-poetry.org/docs/#installation).

2\. Клонируйте репозиторий:



&#x20;  ```bash

&#x20;  git clone https://github.com/TheIsmarin/BankOperationAnalyzer.git

&#x20;  cd BankOperationAnalyzer

&#x20;  ```



3\. Установите зависимости:



&#x20;  ```bash

&#x20;  poetry install

&#x20;  ```



4\. Создайте `.env` из шаблона и укажите ключ APILayer:



&#x20;  ```bash

&#x20;  cp .env\_template .env

&#x20;  ```



&#x20;  Внутри:



&#x20;  ```

&#x20;  API\_KEY=ваш\_ключ\_apilayer

&#x20;  ```



5\. Положите файл `operations.xlsx` в папку `data/` (если его нет в репозитории).



\## Запуск



```bash

poetry run python -m src.main

```



В консоль выведется JSON для Главной страницы и для Событий (диапазоны W, M, Y, ALL).



\## Тесты



```bash

poetry run pytest -v

```



42 теста: приветствие по времени, карты, топ-5, структура JSON, диапазоны, топ-7 + Остальное, поиск, телефоны, переводы физлицам, кешбэк, декоратор отчётов. API в тестах подменяется через `Mock`/`patch` — реальный ключ не расходуется.



\## Переменные окружения



| Переменная | Назначение |

|---|---|

| `API\_KEY` | Ключ APILayer для курсов валют и цен акций |



\## Примечание об API



Для реального получения курсов валют и цен акций нужен действующий ключ APILayer с подпиской на соответствующие эндпоинты. Без ключа (или при недоступности API) блоки `currency\_rates` и `stock\_prices` возвращаются пустыми, а ошибки логируются — программа не падает.
